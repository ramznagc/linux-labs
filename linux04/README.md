# 🐧 Linux Hands-on 04 - sed, awk & Crontab

## 📖 Overview

This hands-on introduces powerful Linux text-processing utilities and task automation using Cron.

The lab focuses on editing text streams, extracting structured data, and scheduling recurring jobs.

---

## 🎯 Learning Outcomes

After completing this hands-on, I can:

- Use the `sed` stream editor
- Process structured text using `awk`
- Extract columns and filter data
- Schedule recurring tasks using Crontab
- Understand Cron expressions
- Automate administrative tasks

---

## 📚 Topics Covered

### sed

- Search and Replace
- Global Replacement
- Case Insensitive Replacement
- Replace on Specific Lines

### awk

- Print Fields
- Custom Delimiters
- Pattern Matching
- Column Processing

### Crontab

- Cron Syntax
- Cron Expressions
- Schedule Jobs
- List Existing Jobs

---

## 🧰 Common Commands

```bash
sed
awk
crontab -e
crontab -l
```

---

## Key Takeaways

- sed edits text streams efficiently.
- awk processes structured text.
- Crontab automates repetitive Linux tasks.
- Text processing is essential for Linux administration and DevOps.

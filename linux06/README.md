# Linux Conditional Statements

This project contains Bash shell scripting examples focused on conditional statements.

## Topics

- If statements
- If Else statements
- If Elif Else statements
- Nested If statements
- String operators
- File test operators
- Boolean operations
- Case statements

## Files

- `if-statement.sh` - Basic if statement
- `ifelse-statement.sh` - If and else conditions
- `elif-statement.sh` - Multiple conditions with elif
- `nested-if-statement.sh` - Nested conditional statements
- `string-operators.sh` - String comparisons
- `file-operators.sh` - File and directory tests

## Numeric Operators

| Operator | Meaning |
|---|---|
| `-eq` | Equal |
| `-ne` | Not equal |
| `-gt` | Greater than |
| `-lt` | Less than |
| `-ge` | Greater than or equal |
| `-le` | Less than or equal |

## String Operators

| Operator | Meaning |
|---|---|
| `=` | Equal |
| `!=` | Not equal |
| `-z` | Empty string |
| `-n` | Not empty |

## File Operators

| Operator | Meaning |
|---|---|
| `-d` | Directory |
| `-f` | Regular file |
| `-r` | Readable |
| `-w` | Writable |
| `-s` | File size greater than 0 |
| `-x` | Executable |

## Boolean Operators

| Operator | Meaning |
|---|---|
| `!` | NOT |
| `&&` | AND |
| `||` | OR |

# 🐧 Shell Scripting Basics

## Overview

This project introduces the fundamentals of Bash shell scripting, including script creation, executable permissions, comments, variables, command substitution, user input, arrays, and basic arithmetic operations.

---

## Topics Covered

- Bash Scripts
- Shebang
- Executable Permissions
- Comments
- Here Documents
- Variables
- Command Substitution
- User Input
- Command-Line Arguments
- Arrays
- Arithmetic Operations

---

## Learning Objectives

- Create Bash scripts
- Execute shell scripts
- Work with variables
- Read user input
- Use command substitution
- Perform arithmetic operations
